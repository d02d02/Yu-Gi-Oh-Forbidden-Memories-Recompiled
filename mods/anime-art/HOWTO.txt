ANIME ART - quick how-to
========================

What it is
----------
Anime-style card frames for Yu-Gi-Oh! Forbidden Memories Recompiled (v0.3.0 or newer).
Every big card view (card viewer, duel hand, field cards, results) gets a full-bleed frame:
the picture fills the card and ATK/DEF sit in the two plaques of the frame.
It is a standalone mod. It does not need the Forbidden Memories HD pack, and it never
changes a card's name, text, picture or stats.

Install
-------
1. Close the game.
2. Unzip into the game folder, the one that holds memories-pc.exe, so that this file exists:
   mods/anime-art/mod.json
3. Start the game and press F10 for the menu bar: Game > Mods > Anime Art.
4. FIRST START: switch "Anime card frame" ON. (The game only keeps a setting once you have
   saved it, so the frame starts switched off. You do this once.)
5. Best look: Video > Resolution > Internal 4x.

Options (Game > Mods > Anime Art)
---------------------------------
Anime card frame       on/off. Off = every card view looks like the original game.
                       Starts OFF: switch it on once (see Install).
Ritual spells: green frame
                       off = ritual spells wear the blue ritual frame (default).
                       on  = ritual spells wear the green magic frame.
Smooth card art        on/off. Shows the card pictures enlarged so the anime frame does
                       not stretch them into stair-steps at Internal 4x. These are the
                       Forbidden Memories HD card pictures (credit: Unchiga, X@nder),
                       enlarged. Off = the game's own pictures (or the HD pack's).

Which frame a card gets
-----------------------
Monster ................ gold
Effect monster ......... orange
Spell, equip ........... green
Trap ................... pink
Ritual spell ........... blue (or green with "Ritual spells: green frame")
Ritual monster ......... blue, two plaques. The 24 monsters that the game's ritual table
                         summons get it automatically (Black Luster Soldier, Gate Guardian,
                         Blue-eyes Ultimate Dragon, Zera, Yamadron, Super War-lion ...).
Fusion ................. purple. Chosen by you, see below.
Obelisk / Ra / Slifer .. blue / yellow / red god frames. Chosen by you, see below.

Giving a card a frame (fusion, ritual, god ...)
-----------------------------------------------
The game has no fusion monsters or gods, so you decide which cards wear those frames.
A card wears a frame because it has a TAG. You give tags in a small mod of your own:

1. Make a folder  mods/my-frames
2. Put a file  mod.json  in it, with this text:

   {
       "id": "my-frames",
       "name": "My frames",
       "min_api": 11,
       "enabled": true,
       "after": ["anime-art"],
       "cards": [
           { "replace": "Thousand Dragon", "tags": ["fusion"] },
           { "replace": 392,               "tags": ["fusion"] }
       ]
   }

3. Start the game. Thousand Dragon and Metalzoa (id 392) now have the purple fusion frame.

(A ready, tested copy of this is in  mods/anime-art/examples/my-anime-frames . Copy that
folder up into mods/ and edit it.)

The rules
---------
- A card is written by its NAME ("Thousand Dragon") or its ID number (1 to 722).
  notes/card-catalog.csv in the game's source lists the ids.
- A tag is ONE word, written exactly like the table below. One tag word per frame.
  "ritual/blue" is not a tag. Write "ritual" or "blue".
- Several cards: one line per card, separated by commas, the last line without a comma.
- Your entry changes nothing else about the card: its name, text, picture and stats stay.
- "after": ["anime-art"] makes your mod load after Anime Art. Keep it.

Tag words
---------
fusion or purple ...... purple fusion frame
ritual or blue ........ blue ritual-monster frame
obelisk ............... Obelisk god frame (blue)
ra .................... Ra god frame (yellow)
slifer ................ Slifer god frame (red)

Examples (one line each, put them in the "cards" list)
------------------------------------------------------
Purple fusion frame by name:
   { "replace": "Thousand Dragon", "tags": ["fusion"] }

Purple fusion frame by id:
   { "replace": 392, "tags": ["fusion"] }

Blue ritual-monster frame on a card that is not a ritual monster:
   { "replace": "Dark Magician", "tags": ["ritual"] }

Take the blue ritual frame away from a ritual monster (it goes back to gold):
   { "replace": 364, "tags": [] }

God frames (cosmetic on the vanilla game, which has no god cards):
   { "replace": "Blue-eyes Ultimate Dragon", "tags": ["obelisk"] }
   { "replace": 1, "tags": ["slifer"] }
   { "replace": "Dark Magician", "tags": ["ra"] }

If a mod adds Obelisk, Ra or Slifer cards, tag them "obelisk", "ra", "slifer" the same way.

Quick test
----------
With the optional Test scenes mod: on the title screen hold L1 and press confirm on Option.
A duel opens with ten monsters on the field. Press Triangle on a card to open the viewer.

Good to know
------------
- Only one mod's card layout is used at a time. Anime Art loads after Forbidden Memories HD,
  so with both installed the Anime Art frames are shown. Frame rules you wrote inside the HD
  pack's own mod.json are not used while Anime Art is on. Tags are: they belong to the cards.
- Card pictures: Anime Art carries the enlarged HD card pictures (Smooth card art). If you
  turn off "Card art" in the HD pack, also turn off "Smooth card art" here.
- The frame pictures have power-of-two sizes on purpose. A frame picture of another size can
  be invisible at Internal 2x/4x on some graphics cards in game version v0.3.0.
