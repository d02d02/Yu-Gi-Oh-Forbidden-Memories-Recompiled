ANIME STYLE - quick how-to
========================

What it is
----------
Anime-style card frames for Yu-Gi-Oh! Forbidden Memories Recompiled (v0.3.0 or newer),
with the Forbidden Memories HD pictures built in.
Every big card view (card viewer, duel hand, field cards, results) gets a full-bleed frame:
the picture fills the card and ATK/DEF sit in the two plaques of the frame.
It is a standalone mod: you do NOT need the Forbidden Memories HD pack. It never changes a
card's name, text, picture or stats.

Install
-------
1. Close the game.
2. Unzip into the game folder, the one that holds memories-pc.exe, so that this file exists:
   mods/anime-art/mod.json
3. Start the game. Everything is ON by default: the anime frames and the HD pictures.
   Game > Mods shows the mod as "Anime Style" (press F10 for the menu bar).
4. Best look: Video > Resolution > Internal 4x, and Video > HD text on.

Options (F10 > Game > Mods > Anime Style)
---------------------------------------
Anime card frame       on (default) / off. Off = every card view looks like the original game.
HD assets              on (default) / off. On = the Forbidden Memories HD pictures everywhere:
                       card art, thumbnails, stars, attribute balls, Build Deck screen, duel
                       arena and HUD, portraits. Off = the original game pictures.
Ritual monster frames  off (default) / on. On = the known ritual monsters (the 24 that the
                       game's ritual table summons: Black Luster Soldier, Gate Guardian,
                       Blue-eyes Ultimate Dragon, Zera, Yamadron, Super War-lion ...) wear the
                       blue ritual-monster frame.
Fusion monster frames  off (default) / on. On = the well-known fusion monsters (Thousand Dragon,
                       Metalzoa, Gaia the Dragon Champion, Flame Swordsman, Darkfire Dragon,
                       Flame Ghost, B. Skull Dragon, Twin-headed Thunder Dragon, Meteor B.
                       Dragon) wear the purple frame.
Ritual spells: green frame
                       off (default) = ritual spells wear the blue ritual frame.
                       on            = ritual spells wear the green magic frame.

Which frame a card gets
-----------------------
Monster ................ gold
Effect monster ......... orange
Spell, equip ........... green
Trap ................... pink
Ritual spell ........... blue (or green with "Ritual spells: green frame")
Ritual monster ......... blue, two plaques. The 24 known ritual monsters get it when
                         "Ritual monster frames" is on; any other card when you tag it.
Fusion ................. purple. The well-known fusion monsters get it when "Fusion monster
                         frames" is on; any other card when you tag it.
Obelisk / Ra / Slifer .. blue / yellow / red god frames. Chosen by you, see below.

Giving a card a frame (fusion, ritual, god ...)
-----------------------------------------------
The game has no fusion monsters or gods, so you decide which cards wear those frames.
A card wears a frame because it has a TAG. You add tags in Anime Style's own mod.json:

1. Open  mods/anime-art/mod.json  in a text editor (Notepad is fine).
2. Find the "cards" list. It holds one line per card: the known ritual monsters (tag
   "known_ritual") and the known fusion monsters (tag "known_fusion"), for example:
       { "replace": 356, "tags": ["known_ritual"] },
       ...
       { "replace": 713, "tags": ["known_fusion"] }
   ]
   These two tags only show a frame while their option (above) is on. Your own tags below
   always show.
3. Add your own lines at the END of the list. Every line ends with a comma EXCEPT the last
   one. So put a comma after the 713 line and add yours, for example:

       { "replace": 713, "tags": ["known_fusion"] },
       { "replace": "Dark Magician", "tags": ["fusion"] },
       { "replace": 1, "tags": ["slifer"] }
   ]

4. Save the file and start the game. Dark Magician now has the purple fusion frame and
   Blue-eyes White Dragon the Slifer frame, whatever the options say.

Tip: an update of Anime Style replaces mod.json. Keep a copy of your lines, or put them in a
mod of your own instead, which survives updates (see "Your own mod" below).

The rules
---------
- A card is written by its NAME ("Thousand Dragon") or its ID number (1 to 722).
- A tag is ONE word, written exactly like the table below. "ritual/blue" is not a tag:
  write "ritual" or "blue".
- To change a known ritual or fusion monster, change its own line ("known_ritual" to
  "fusion", or to [] for the plain gold frame). A second line for the same card also works;
  the game then writes a harmless note in its log.
- Your line changes nothing else about the card: its name, text, picture and stats stay.

Tag words
---------
fusion or purple ...... purple fusion frame
ritual or blue ........ blue ritual-monster frame
obelisk ............... Obelisk god frame (blue)
ra .................... Ra god frame (yellow)
slifer ................ Slifer god frame (red)

Examples (one line each, in the "cards" list)
---------------------------------------------
Purple fusion frame by name (always, whatever the options say):
   { "replace": "Dark Magician", "tags": ["fusion"] }

Purple fusion frame by id:
   { "replace": 392, "tags": ["fusion"] }

Blue ritual-monster frame on a card that is not a ritual monster:
   { "replace": "Celtic Guardian", "tags": ["ritual"] }

Keep one known ritual monster gold even when "Ritual monster frames" is on:
   { "replace": 364, "tags": [] }

God frames (cosmetic on the vanilla game, which has no god cards):
   { "replace": "Blue-eyes Ultimate Dragon", "tags": ["obelisk"] }
   { "replace": 1, "tags": ["slifer"] }
   { "replace": "Dark Magician", "tags": ["ra"] }

If a mod adds Obelisk, Ra or Slifer cards, tag them "obelisk", "ra", "slifer" the same way.

Your own mod (survives updates)
-------------------------------
Instead of editing Anime Style's mod.json you can keep your lines in a separate mod:
make a folder mods/my-frames with a mod.json holding
   { "id": "my-frames", "name": "My frames", "min_api": 11, "enabled": true,
     "after": ["anime-art"],
     "cards": [ { "replace": "Thousand Dragon", "tags": ["fusion"] } ] }
A ready copy is in  mods/anime-art/examples/my-anime-frames .

Quick test
----------
With the optional Test scenes mod: on the title screen hold L1 and press confirm on Option.
A duel opens with ten monsters on the field. Press Triangle on a card to open the viewer.

Good to know
------------
- The HD pictures are inside this mod, so you do NOT need to install the Forbidden Memories
  HD pack. If you already have it installed, nothing breaks: leave it there or delete it, you
  see the same HD pictures either way.
- Only one mod's card layout is used at a time. Anime Style loads after Forbidden Memories HD,
  so with both installed the Anime Style frames are shown. Frame rules you wrote inside the HD
  pack's own mod.json are not used while Anime Style is on. Tags are: they belong to the cards.
- The mod has one tiny piece of code (anime-art.o): at start it switches "Anime card frame"
  on if you have never chosen. Your own choice is kept after that.
- The frame pictures have power-of-two sizes on purpose. A frame picture of another size can
  be invisible at Internal 2x/4x on some graphics cards in game version v0.3.0.

What changed in 1.2.3
---------------------
- Cards of different frame kinds on screen together (the attacker and its target, a trap shown
  beside its attacker) each keep their own frame colour during the duel. Before, a card could
  fall back to another card's frame (the "colours return to normal" bug).
- The attack animation no longer slows down when a card with a god / fusion / ritual frame
  attacks.
- These two fixes are in the game program, not in the mod files: use the memories-pc.exe that
  comes with the "fix pack" zip (replace the one in your game folder). With the plain v0.3.0
  memories-pc.exe the mod works as before.
