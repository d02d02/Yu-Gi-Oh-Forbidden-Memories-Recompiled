# Job e7-stream

## Goal
Frame stream from the running game to the Studio (Route B, need E7), phase 1, pure Python, no C change. The control channel already has `shot <path>` (the presented VRAM frame as PNG) and `hash` (FNV-1a of VRAM). Build `FrameStream` on top of them: polls the game, yields only frames that changed, at a capped rate, so a viewport can show a live picture. Phase 1 = make it work and measure; if the measured rate is too low, say so in the final message (phase 2 would add a C command).

- New module: `tools/hd-models/studio/stream.py`. API:
  - `class FrameStream(game, fps=10.0, max_frames=None, out_dir=None)`; `game` is any object with `.shot(path)` and `.hash()` (tests pass a fake).
  - `frames()` generator: every `1/fps` s (use an injectable `clock` and `sleep`, default `time.monotonic` / `time.sleep`) ask `game.hash()`; if equal to the last yielded hash skip; else `game.shot(<out_dir>/f<seq>.png)`, read the bytes, delete the file, yield `Frame(seq, hash, png_bytes, t)`; `seq` counts yielded frames from 0. Stop after `max_frames` yielded frames, or when `close()` is called, or when the game raises `ControlError` (store it in `self.error`, do not raise out of the generator).
  - `stats()` returns `{"frames": n, "polls": n, "skipped": n, "mean_ms": float, "fps": float}` (mean_ms = mean time of the shot call, fps = yielded frames per second of wall time).
  - `latest()` returns the most recent Frame or None. A consumer that is slower than the stream must not make frames pile up: the generator is pull-based, no queue.
- Demo: `tools/hd-models/stream_demo.py --selftest` runs without the disc on a fake game (a counter that changes hash every 3rd poll, `shot` writes a tiny valid PNG made with zlib/struct, no Pillow needed) and prints the stats; without `--selftest` it starts the real game like `tools/hd-models/field_attack.py` does (read its header and `grep -n "def "`; needs `MEMORIES_DISC`), streams 3 s to `tmp/pc/stream/` as numbered PNGs and prints the stats. The real run is NOT checked by the harness (no display, no disc).
