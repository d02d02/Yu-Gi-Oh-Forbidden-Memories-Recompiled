# Kuriboh in the port: design review (2026-10-10; compacted 2026-10-13)

Layers: data mod (`mod.json`, `duelists/`, `decks/`, `drops/`, `text.txt`: cards, fusions, equips, limits, terrain by type, trap thresholds, frame colors, 15 added + 38 replaced duelists, 283 dialogue strings) = clean; the old 36 MB `WA_MRG.MRG` blob = the mess (card art, plates, passwords, portraits, duel package, duelist records); `mods/kuriboh-rules` C workarounds; small generic engine changes (`any_card` equips, magic-card equip placement).

**Done:** terrain bonus per card (`terrain_bonus` `cards`), copies per card (`limits.card_copies`, also fixes the red count), unique first-win drop (`unique_drops` in `CardDrops_Roll`) are port features/data; `kuriboh-rules` deleted; the blob is gone (art, thumbnails, plates as editor art files, four `portraits/*.png`; mod folder 1.5 MB). Extra duelists are clean (ids 40-54 are what dialogue scripts say, so the mod must be the first to add duelists; `slot` pins them). Rituals as fusions, Exodia rank, Spellbinding 700, trap threshold, frame colors = data.

**Stays code, one small documented hook each with a test, no frame callbacks:** mode 11 roll, AI variable for modes 10-13/15, Exodia result screen (cosmetic, skip), House of Adhesive Tape/Mirror Force effect, music per opponent, the harder discs' AI. **Variants as deltas:** `kuriboh-pharaoh`, `kuriboh-god` mods requiring `kuriboh` (limits, AI rows, drop count, starter decks, AI hooks). Keep `python tools/pc/fm_editor import <disc>` the single producer: nothing of the ROM hack is committed.
