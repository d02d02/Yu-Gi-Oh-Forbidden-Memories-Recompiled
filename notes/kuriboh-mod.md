## The spec (author's list, translated) and where each lives
Extra duelists (ids 40-55, mode = id - 39) are started by campaign **dialogue scripts** (`{f8 0D opp b370 b372 terrain bgm_lo bgm_hi}` = `Text_StartCampaignDuel`: opponent, two story strings before/after, terrain, music; retail 59 starts, Kuriboh 88); not reachable from Free Duel (`unlock` never holds). Base mod: (1) 2 extra unlockable characters (one is Yugi Moto as an adversary); (2) 15 extra campaign-only characters; (3) harder anime-like decks (byte pools); (4) one drop, a unique iconic card on first campaign win per duelist (`unique_drops`); (5) 17 new cards; (6) more fusions incl. rituals with their monsters; (7) per-card terrain bonuses (Yami raises Heishin's monsters); (8) Exodia win = S-TEC; (9) all 722 cards by drop or password; (10) new campaign events (hidden hard enemies); (11) three difficulties = three discs (Pharaoh: opponents fuse/equip from the start and change guardian stars, iconic Yugi/Atem starter deck, better unique drops, easier S-A POW, S-A TEC only with Exodia, five cards limited to 1 copy; alt disc: drop x5, Yugi/Joey/Kaiba starter decks. GOD: six type-based starter decks, max stats, no unique drops, 10 cards a win, every opponent has an affinity field, same limits). Millennium Challenge: separate disc on a finished save, 55 opponents, no saving, no banlist, opponents first, 15 cards a win. (12) Data source: the TEA database (basededatostea.xyz/extend). Also: 1-copy limits (base: 3 everywhere, Exodia pieces 1, card 679 Novox's Prayer 0; Pharaoh/drop-5/GOD add 1 copy for Dark Hole 336, Raigeki 337, Swords of Revealing Light 348, Crush Card 661, House of Adhesive Tape 681), AI changes, starter-deck choosers.
Extras (script strings): 40 (mode 1, `[05AD]` old man Run/Stay), 41 (`[0505]` Simon Muran 2nd), 42 (`[053C]` Heishin's guards, flag 404D), 43 (`[05A8]`), 44 (`[055F]` after game over: Shop/Duel, `{choose 80 L714D L73B0}`), 45 (`[0553]`), 46 (`[0543]`), 47 (`[0585]` Valley of the Kings guard), 48 (`[05F0]` Teana/Jono, sets 40FD), 49 (`[0548]` the dream), 50 (`[0557]` Joey), 51 (`[05D2]` Heishin DarkNite), 52 (`[0558]` terrain 3), 53 (`[05CF]`), 54 (`[0524]`, same strings as opponent 0's final duel `[056A]`/`[0524]`, "the Unused" Yugi-and-Atem duel). Names (`0x801DB3A8 + 24*mode`): Simon Muran 2nd, Lady Palace, Dark Shrine Guardian, Guardian Palace, Card Shop Owner, Tea Gardner, Joey Wheeler, Sadin, Jono 3rd, Pharaoh Atem, Duel Master K, Heishin 3rd, Pharaoh Seto, Yami Bakura 2nd, Undefeated Yugi. Each base slot k (1-15) keeps TWO byte pools in each of 4 regions (deck, pow, bcd, tec): `[0:722]` for itself, `[722:1444]` for its mode-k twin, each summing to 2048, plus a second AI row at `0x801CF3F7 + 9k`. Port `duelists` feature: `copy` base, `slot` = 39+k, own `decks`, `drops`, `ai`, `name`, `unlock`.

## How the mod patches the executable (analysis; tools `exe_diff.py`, `exe_dis.py`, `cave_dis.py`)
`python tools/pc/kuriboh/exe_diff.py <retail .bin> <modified .bin> -o tmp/kuriboh/exe_diff.txt`. Base mod: 38 functions/symbols, ~30 hooks into **code caves**: cave A `0x801CEFEC-0x801CFF87` (entries `0x801CF320`..`0x801CF840`, per-card copy-limit table `0x801CF030`, per-mode tables `0x801CF400`..), cave B `0x801DB010-0x801DBA08`, plus `0x801CE00C`. Variants change 47-48 symbols (also `AiScript_FindWeakest/FindKiller`, `Ai_CompleteFusion`, `AiScript_FindBestAttack`, `func_80027DF8`, `func_80037DA4`): do the base first, express variants as deltas. `cave_dis.py` needs `pip install --target tmp/kuriboh/pylib capstone` and `PYTHONPATH=tmp/kuriboh/pylib`.
- Mode byte `0x801CF310` (+ signed halfword `0x801CF312`, -1 unset; `0x2D2` = "no card"): `Text_StartCampaignDuel` hook (`0x801CF320`) stores `id - 0x27` for ids > 39. Hooks that read it: `Ai_GetHandSize` (`0x801CF570`), `AiScript_LoadOpponentData` (`0x801CF5A0`), `Duel_InitScene` (`0x801CF600`: only mode 5 shifts the drop pool by 722 and lets ids up to 0x126 through; `0x801CF770`: mode 11 rolls 0-39 into `0x801D0708`, others -1), `func_800383DC` (`0x801CF640`, 24-byte rows), `AiScript_Store` (`0x801CF6B0`: modes 10-13, 15 pass the mode as AI variable 15), `Duel_SelectCardDrop` (`0x801CF394`, `0x801DB2B0`; per-card no-drop bit table `0x801D06F4`), `Duel_ShuffleDeck` (`0x801CF344`: ids 1-15 patch the shuffle at runtime: `lhu`->`lbu` at `0x80024474`, stride 2->1 at `0x800244D4`, loop to 722; for a roll < 16 base pool else the unpatched shuffle).
- Card frame colour: `func_800291E0`, `func_8002BFCC` (112 B), `0x801DB840` read a nibble per card at `0x801DB8A0` (0-5 = variant). Copy limits: `BuildDeck_UpdateChestPaneInput` (`0x801CF000`, table `0x801CF030`). Terrain: `DuelEffect_ApplyTerrain` (`0x801CFB00`) and `Duel_SetupCardRecord` (`0x801CFB50`) look cards up in `0x801CFA20` (32-byte rows by terrain byte `0x800AB364`: halfword ids to a 0, bonus at +0x1E; 84 cards, +500). Exodia hooks (`0x801CFEC0..0x801CFF3C`) watch card `0x2A7` and rewrite the five result entries to ids 17-21 (cosmetic/unused: do not reproduce). Plain edits: card count `0x2D0 -> 0x2D2/0x2D3`, `0x28 -> -0x7F`, `slti 0x27 -> 0x127`, stat penalty -500 -> -700 (`DuelEffect_ApplyStatPenalty`, Spellbinding Circle `0x80025E60/6C`; Shadow Spell stays 1000), flag mask `0x80 -> 0` at `0x8001E3BC` (`DuelScene_UpdateFieldActions`), `blez -> bltz` (`Text_UnlockDuelist`), Exodia -127 instead of +40 in rank sum (`0x800215F4`, `0x800183D0`, `0x800193DC`; port `limits.rank_score.exodia` = -99).
- RAM dumps (4, DuckStation): duelist byte `0x8009B361`, terrain `0x8009B364`, mode byte 0 in all: normal Free Duel never enters modes (my dumps missed the dialogue-started duels).
- Hook mechanics in the port: `host->hook(host, <game fn>, <mine>, &original)` chains/removes (`notes/modding.md` "Code hooks"; examples `mods/ai-hard-mode`, `mods/yamyi-mods`); extra duelists are data (`notes/more-duelists.md`).
- Importer corrections: deck/drop pools of duelists 1-15 are ONE BYTE a card (60 pools sum to exactly 2048; read as halfwords they gave 495226); the earlier "40 fixed decks" was a false positive (`deals_by_count` fired on any loop change; retail already ends at `slti 40`); `read_byte_pools` reads them. Spellbinding Circle 700 (`limits.spellbinding_circle`).
- Rituals are fusions: one ritual-table entry kept (retail 24), each ritual spell fuses with each monster of its set (644 pairs); `test_ritual.py`: Zera Ritual + Ryu-kishin = Zera the Mant.
- Magic cards as equips: rows for 338 Multiply (Kuriboh 58, 343 ...), 349 Spellbinding Circle (35, 693, 722), 669 Shadow Spell (693); bonus in placement hook `0x801AAC30` (called at `0x8001A814`): 338 +2500, 669 +2000, 349 +1000, 668 Bright Castle +700, others retail (+500, Megamorph +1000); `0x801AAC00` (at `0x8001AAA0`) treats kind 0x14 as 0x17. Done via `any_card` + `Tables`/placement change (checked: +1000, +2000 land).
